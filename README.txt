INNER GLOW THERAPY CIC — Scroll-Built V8

Open index.html directly in Chrome, Edge or Safari.
No build step is required.

Key changes:
- Homepage is progressively “painted/built” as you scroll.
- Fixed jump rail lets visitors skip straight to Make / Move / Meet / Breathe / Together / Create.
- Lightweight SVG stroke and transform-only brush movement; no heavy animation library.
- Dedicated desktop/laptop, iPad/tablet and phone layouts.
- Public-domain Openclipart assets are bundled locally; see ASSET-SOURCES.txt.
- System font stack for reliable local/offline rendering and legibility.
- Reduced-motion support.
- Existing multi-page site and Create Online drawing functionality retained.
