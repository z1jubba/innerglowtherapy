INNER GLOW THERAPY CIC — V16 APP/AUDIO PASS

Changes in this build:
- Activities page loops assets/audio/activities-bg.mp3.
- Create Online loops assets/audio/create-bg.mp3.
- Browsers block audible autoplay until the visitor interacts with the page. The soundtrack starts on the first tap/click/key interaction when sound is enabled.
- A persistent Sound/Music control is added in the header.
- Lightweight UI/paint/transition sound effects are generated with the Web Audio API, so there are no extra SFX downloads.
- Tablet and phone layouts use an app-style bottom dock plus a More sheet.
- Mobile/tablet content is recomposed into screen/card layouts instead of squeezed desktop columns.
- The Community connection diagram was rebuilt visually so the global paint path no longer cuts through it and the centre hub is no longer doubled.
- The Create Online canvas is prioritised before the tool panels on small screens.

IMPORTANT MUSIC NOTE
The two music files in this package were supplied by the site owner/user. Before publishing them publicly on GitHub Pages or another website, make sure the organisation has the necessary rights/licences for public web use. This build does not grant music rights.
